# Crédits — modèles 3D d'animaux

Tous les fichiers viennent de [Poly Pizza](https://poly.pizza) (fichiers GLB statiques `static.poly.pizza/<id>.glb`). Licences vérifiées sur la page de chaque modèle le 18/10/2026.

Modifications apportées (autorisées par les deux licences) : textures intégrées réduites à 512×512 maximum ; pour `squirrel`, `bee`, `flamingo` et `stork`, ajout d'un nœud racine `Reoriented` (rotation) pour que tous les modèles regardent vers +Z, axe Y en haut. La géométrie n'a pas été modifiée.
